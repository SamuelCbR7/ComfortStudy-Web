# ComfortStudy — Aba Calendário

Arquivos:
- calendario.html
- style_calendario.css
- script_calendario.js

## Como usar
Coloque os 3 arquivos na mesma pasta do seu projeto e abra `calendario.html`.

## Funcionalidades
- Calendário mensal com navegação anterior/próximo.
- Botão "Hoje".
- Criar atividade clicando em "＋ Nova atividade".
- Criar atividade clicando diretamente em qualquer dia.
- Editar atividade clicando nela.
- Excluir atividade.
- Marcar atividade como concluída.
- Pesquisa por nome/matéria.
- Filtro por Prova, Trabalho, Estudo e Outro.
- Lista de próximas atividades.
- Resumo automático do mês.
- Dados salvos no `localStorage` do navegador, sem banco de dados.

## Integrar com sua barra lateral atual
Substitua o link atual do item Calendário por:
<a href="calendario.html">▣ <span>Calendário</span></a>

Se quiser que Dashboard/Matérias/Tarefas continuem funcionando, mantenha os nomes dos seus arquivos atuais e apenas aponte o link do Calendário para `calendario.html`.
